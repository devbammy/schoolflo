Based on what's been built so far, here are the features that are still missing but genuinely critical for a production school management portal:

**Academic & Learning** [x]

- **Library Management** — book inventory, borrowing/return tracking, overdue notices per student
- **Examination Scheduling** — formal exam timetable separate from class timetable, with invigilation assignments
- **Continuous Assessment Tracking** — term-by-term progression charts showing improvement or decline over multiple academic years
- **Promotion / Class Advancement** — end-of-year logic to move students from JSS1 → JSS2, handle failures and repeats
- **Certificate & Document Generation** — PDF export of report cards, school leaving certificates, admission letters

**Administrative**

- **Staff Payroll & Salary Management** — salary records, deductions, payslip generation for teachers and staff
- **Student Admission Portal** — online application form, document upload, admission approval workflow with status tracking
- **ID Card Generation** — printable student and staff ID cards with photo, class, and admission number
- **Academic Calendar** — term start/end dates, holidays, events, and school-wide important dates visible to all roles
- **Hostel / Boarding Management** — room allocation, bed assignment, boarding fees separate from day fees

**Communication**

- **Internal Messaging / Chat** — direct messages between teachers and parents, or admin and staff, without leaving the portal
- **Event Management** — create school events (PTA meetings, sports day, graduation), RSVP tracking, reminders
- **Push Notifications** — real-time browser/mobile push for new results, fee reminders, announcements
- **Bulk SMS / WhatsApp Integration** — Nigerian-specific; Termii or Africa's Talking integration for fee reminders and result alerts

**Finance**

- **Expense Tracking** — record school expenditures (utilities, supplies, maintenance) against income
- **Bursary / Scholarship Management** — partial fee waivers, scholarship students, discount tracking per student
- **Debt Ledger** — running balance across multiple terms showing cumulative unpaid fees per student
- **Invoice Generation** — printable/downloadable fee invoices parents can present at the bank

**Reporting & Analytics**

- **School-wide Analytics Dashboard** — pass rates per subject, average scores by class, attendance trends over time, teacher performance metrics
- **Custom Report Builder** — admin-configurable reports (e.g. all students with >3 absences this week, all unpaid fees above ₦50,000)
- **End-of-Term Summary Reports** — automated per-class PDF reports for principal review

**Security & Operations**

- **Audit Log** — every sensitive action (delete student, publish results, record payment) logged with timestamp and user
- **Role Permission Granularity** — sub-roles within Admin (Bursar handles only finance, Class Teacher handles only their class)
- **Data Backup & Export** — full school data export to CSV/Excel for offline records or migration
- **Two-Factor Authentication (2FA)** — OTP via SMS or email for admin and staff logins
- **Session Management** — view and revoke active login sessions per account

**Portal Usability**

- **Mobile App (PWA)** — the web app installable on phones as a Progressive Web App with offline support for attendance marking
- **Dark Mode** — toggle in user settings
- **Multi-School / Multi-Branch Support** — single portal managing multiple campuses under one admin account
- **Onboarding Wizard** — step-by-step setup guide for new schools (create classes → add subjects → enroll students → set fees)

---

The most impactful ones to build next for a Nigerian school context, in order of priority, would be: **Academic Calendar**, **Admission Portal**, **Debt Ledger / Invoice Generation**, **Audit Log**, and **Push Notifications** — these are the ones parents and admins ask about most in day-to-day school operations.
